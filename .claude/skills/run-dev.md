# run-dev

Launch the ReumaIndex development server.

## Description

Starts a Vite development server for local development and testing. The server runs on `http://localhost:8080` with hot module reloading (HMR) enabled.

## Usage

```bash
cd Meddocente.cl && npm run dev
```

## Details

- **Port**: 8080
- **HMR**: Enabled (auto-reload on file changes)
- **Time to ready**: ~300-500ms
- **Output**: Shows local and network URLs in terminal

## When to use

- Testing changes locally before committing
- Debugging components or pages
- Checking responsive design in browser
- Manual verification of features before pushing to production

## Stop the server

Press `Ctrl+C` in the terminal running the dev server.
